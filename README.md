# 短途旅行规划

双击 `index.html` 在浏览器打开（需联网加载地图与图片）。

## 数据范围
- **世界遗产：全部60项**（文化41 / 自然15 / 双重4，截至2025年西夏陵）。
  系列遗产（长城、明清皇家陵寝、苏州园林、福建土楼、丝绸之路、大运河、
  南方喀斯特、中国丹霞、天地之中等）以**二级目录**展示子景点，
  全部子景点均在地图标注，共约160个点位。
- **国保单位：全量收录**。精选69处（含票价/简介等详情）+ 全量约5500处
  （维基数据坐标 × 国家文物局官方名单批次，guobao_full.js），
  可按批次（第一批~第八批/批次待核）筛选。约965处官方名与维基名
  不一致者批次暂标"待核"。
- **博物馆·展览**：精选23座顶级博物馆（含票价/简介）+ 全量358处带坐标博物馆
  （`museums_full.js`，国家一级216 / 二级131 / 国家重点美术馆11），可按等级子筛选。

## 功能
- 分类筛选 + 子筛选（世遗按文化/自然/双重；国保按批次）
- 搜索名称/城市/省份（含子景点）
- 点位聚合显示；详情卡片含类型、评级、星级、票价、开放时间、简介、
  图片（自动从维基百科拉取）、高德导航链接
- 行程清单：按顺序连线、可调顺序、显示总直线距离，自动保存在浏览器
- 底图 OpenStreetMap ⇄ 高德 切换（已做坐标纠偏）

## 全量国保导入（5058处）
公开的全量带坐标数据需自行下载（如 CSDN 上的"全国重点文物保护单位
Excel/Shp 数据"，或国家文物局名录自行匹配坐标）。拿到 Excel/CSV 后：

```bash
pip install openpyxl   # 仅 xlsx 需要
python3 tools/import_guobao.py 下载的数据.xlsx
```

脚本会在项目根目录生成 `guobao_full.js`，刷新页面即自动合并显示全部
国保单位（与精选条目自动去重）。数据列名要求见脚本开头说明。

### 免费批量来源：Wikidata
浏览器打开 query.wikidata.org ，粘贴以下查询 → 点左下 ▶ 运行 →
结果表格上方「下载 ▾」→ CSV，所得文件可直接喂给导入脚本：

```sparql
SELECT ?名称 ?纬度 ?经度 ?批次 WHERE {
  ?item wdt:P1435 ?d .
  ?d wdt:P279* wd:Q1188574 .
  ?item wdt:P625 ?coord ;
        rdfs:label ?名称 . FILTER(LANG(?名称)="zh")
  OPTIONAL { ?d rdfs:label ?批次 . FILTER(LANG(?批次)="zh") }
  BIND(geof:latitude(?coord)  AS ?纬度)
  BIND(geof:longitude(?coord) AS ?经度)
}
```

若超时，删掉 OPTIONAL 那一行再试（批次列可缺省）。
